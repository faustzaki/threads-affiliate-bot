# Gambar Random

Taruh gambar di sini buat post random (bukan affiliate).

- `SIANG/` → buat post siang
- `MALAM/` → buat post malam

**Nama file bebas.** Sistem akan otomatis:
1. Baca gambarnya (vision)
2. Tulis caption yang nyambung
3. Pindah ke pool siap pakai

Cukup drop di sini, lalu jalankan:
```bash
python cek_stok.py
```
